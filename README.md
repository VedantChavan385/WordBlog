WordBlog 🌍✍️

Stories That Matter

WordBlog is a modern, design-driven blogging platform built with HTML, CSS, and Vite.
It empowers writers and creators to share impactful stories, spark meaningful conversations, and connect communities through words.

🚀 Features

✨ Clean and responsive UI design

🎥 Hero section with background video

🎨 Smooth animations with Locomotive Scroll and SwiperJS

📂 Blog categories (Travel, Food, Fitness, Education, Finance, Startups)

👩‍💻 Featured blogs by authors

📱 Mobile-friendly and optimized for all devices

⚡ Powered by Vite for fast development

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Libraries & Tools:

Vite
 – lightning-fast build tool

Locomotive Scroll
 – smooth scrolling animations

SwiperJS
 – carousel & slider support
